# Memomo 승인된 이미지 방향

## 게임 카드
- 스타일: 부드러운 명암과 붓 질감의 따뜻한 일러스트. 이전 여우·딸기·에펠탑·요리사·프라이팬 시안 기준.
- 배경: 투명. 사물/동물은 정중앙 배치. 정답 추론에 도움이 되는 배경·장식·글자 금지.
- 동물 친구들: 30종. 10~30쌍 선택, 직접 고른 수가 부족하면 중복 없이 무작위 보충.
- 맛있는 짝꿍: 과일과 음식 30종. 동물 모드와 같은 방식의 동일 그림 매칭.
- 국기와 랜드마크: 국가의 국기와 대표 랜드마크 연결. 국기는 정확한 도형 그래픽, 랜드마크는 같은 일러스트 스타일.
- 그때와 지금: 기존 물품 15쌍 유지. 기존 단색 아이콘 30장도 새 스타일로 교체. 기존 이미지 파일은 검증된 새 세트가 준비되기 전까지 유지.
- 직업과 도구: 15쌍. 직업과 사용하는 도구 연결.
- 커스텀: 업로드한 동일 이미지 매칭 유지.
- 이미지는 로딩 및 디코딩 완료 후 암기 카운트다운 시작. 이 부분은 src/page/CardFlip.tsx에 선행 적용됨.

## 모드 진입 전용 이미지
게임 카드와는 별도 자산이다. 정답 카드의 예시를 그대로 보여주지 않는다.
커스텀을 포함하여 총 6종, assets/entry-preview/prompts.json에 내장 image_gen 프롬프트를 보관한다.
원본은 assets/entry-preview/{id}.png, 서비스용은 public/concepts/{id}.webp에 저장한다.
assets/entry-preview/index.html은 검수용 정적 진입화면이며 실제 Home.tsx 교체본이 아니다.

## 제작 상태 (2026-10-27)
- 6가지 진입 메뉴와 테마별 설정 화면을 실제 게임에 적용.
- 내부 일러스트 PNG/WebP 135종, 국기 SVG 15종, 진입용 대표 이미지 6종 저장.
- 동물·음식 각 30종, 국기·랜드마크 / 그때와 지금 / 직업·도구 각 15쌍 제공.
- 기존 신구 물품 15쌍은 새 일러스트 30장으로 모두 교체. 예전 파일은 보존하되 현재 게임에서 참조하지 않음.
- 고해상도 원본은 로컬 assets/cards에 보관하고 Git에서 제외. 서비스용 파일은 public/cards에서 사용.
- assets/entry-preview/index.html은 승인 당시의 정적 시안이며 실제 서비스 진입 화면은 src/page/Home.tsx.
